# 文档目录定位模块

这是一个外部进程模块，不链接主程序代码，也不读取作业簿数据库。安装后，作业簿只会把已关联文件的路径交给模块建立本地目录缓存；点击带“页码”或“章节”的作业文件链接时，再把该文件路径和本次关联的位置交给模块打开。

## 安装与热加载

最简单的方式是双击模块目录中的 `install.cmd`。也可以在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\modules\document-navigation\install.ps1
```

然后在“设置 → 其他功能模块”点击“刷新模块”。不需要重新编译或重启作业簿。模块的数据保存在其安装目录的 `data/index.json`，禁用或移除模块不会改动作业记录和原文件。

## 支持范围

| 格式 | 预索引 | 跳转方式 |
| --- | --- | --- |
| PDF | 读取未压缩的 PDF 书签并映射页码 | 页码优先；章节命中书签后转为页码，以浏览器 `#page=` 打开 |
| DOCX | 读取 OOXML 的 Heading/标题样式 | 通过本机 Microsoft Word 定位页码或标题文字 |
| DOC | 不预索引 | 通过本机 Microsoft Word 定位页码或章节文字 |
| HTML/HTM | 读取带 `id` 的 `h1`–`h6` | 以文件 URL 的锚点打开 |

PDF 的页码跳转不依赖书签；章节跳转只对可读取的书签生效。部分 PDF 使用压缩对象流或自定义编码，目录可能无法由无依赖脚本解析，此时模块会打开首页并给出提示。DOC/DOCX 定位需要本机安装 Microsoft Word。

## 安全边界

- 模块只读取宿主明确传入的关联文件，不扫描课程目录。
- 索引与日志都不上传；模块没有网络请求。
- 模块不会写入、移动、复制或删除学习文件。
- 外部模块以当前 Windows 用户权限运行，不是操作系统沙箱；请只安装可信来源的模块。
