# 桌面客户端服务配置文件

桌面客户端从用户数据目录的 **`services.json`** 读取要连接的个人服务。配置独立于可执行文件、安装包、业务数据库和设备授权；同一份通用安装包可以连接不同使用者自己的 Cloudflare 服务。

先安装支持此功能的客户端一次，以后修改服务地址无需重新编译。当前功能属于未发布源码，旧安装包不会自动获得该读取能力。

## 文件位置与内容

在“设置 → 个人多设备同步 → 服务配置文件”点击“打开文件夹”，即可找到它。默认位置：

| 系统 | 文件 |
| --- | --- |
| Windows | `%APPDATA%\app.homeworkbook.local\services.json` |
| macOS | `~/Library/Application Support/app.homeworkbook.local/services.json` |
| Linux | `${XDG_DATA_HOME:-~/.local/share}/app.homeworkbook.local/services.json` |

文件形状如下，将示例源地址替换为自己部署的 HTTPS 地址：

```json
{
  "version": 1,
  "sync": {
    "server_url": "https://your-service.example"
  }
}
```

也可以复制公开的[占位模板](../deploy/client/services.example.json)到上述位置再填写。源地址不能带 API 路径、查询参数、账号或密码；仅本机开发允许 HTTP loopback 地址。空字符串表示尚未选择服务。配置最大 16 KB；暂不接受额外字段。

首次读取时，仅在文件不存在的情况下创建：旧安装将从已有 `sync-device.json` 提取服务地址，保留原有配对和同步偏好；新安装生成空地址，默认不启用同步。已有 `services.json` 始终优先，不与发布包中的默认值合并，也不因启动或升级而重写。

## 修改与连接

1. 编辑文件并保存，或在未连接的同步设置中填写地址并申请配对/初始化；这类明确的连接操作会保存所选地址。
2. 在同步设置点击“重新读取”，也可重新打开设置或重启应用。每次原生同步操作都会读取配置，不缓存编译时地址。
3. 新服务需要重新配对，再确认同步范围、开启同步。单纯填写配置不会授予授权或自动开启数据上传。

旧设备授权始终绑定原服务。选择新源地址后，同步状态变为未连接，旧设备 Token 和未完成的配对不会转发到新地址，运行中的旧同步响应也不能覆盖新连接。原服务的远端授权并未自动撤销，可从原服务的其他已授权设备撤销。

如果 JSON 损坏、包含未知字段、版本过高或源地址不合法，应用会停止连接并显示错误，保留原文件供修复；不会悄悄改用旧地址或样例服务器。即使文件损坏，“打开文件夹”仍可使用。

## GitHub 安装包更新

正常覆盖安装或更新只替换程序文件；`services.json` 位于用户数据目录，应用启动与更新逻辑不覆盖已有内容。公开包不附带实际配置，不携带某个私人服务地址。后续版本应继续使用稳定的应用标识 `app.homeworkbook.local` 与文件格式版本，并为未来格式变更提供兼容读取。

Windows 当前 NSIS 更新模式保留 AppData；普通卸载只有用户另行勾选清除应用数据时才删除该目录。手动清空用户数据目录、更换系统用户或显式选择清除数据不属于保留配置的升级路径。

业务数据库备份/恢复和断开设备不会替换服务文件。需要迁移设置时单独复制 `services.json`；它不包含授权，新设备仍须配对。不要把真实文件提交 Git、公开上传，或随通用安装包分发。

## 凭据与其他平台

- 文件只保存客户端服务源地址，不保存 Cloudflare 管理 Token、初始化密钥、OAuth Client Secret、模型 API Key 或设备 Token。未知凭据字段会被拒绝。
- 设备授权继续保存在 Windows Credential Manager、macOS Keychain 或 Linux Secret Service；`sync-device.json` 只保存设备身份、原服务绑定及运行状态。
- 桌面 AI Key 仍在系统凭据库；网页 AI 与 Drive 授权仍由自己的私有 Worker 管理，不通过此文件设置。
- 网页/PWA 使用所打开站点的同源 API，不能读取电脑上的配置文件。更换网页服务应访问自己部署的新站点并重新授权。
- Cloudflare 资源部署配置是另一个用途的仓库外文件，不要将 `cloud.json` 复制到客户端。部署步骤见[自托管指南](../deploy/cloudflare/README.md)。
